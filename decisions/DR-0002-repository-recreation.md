# DR-0002 · 공개 저장소 재생성과 커밋 개인정보 보호

- 상태: Accepted (인프라 복구 범위)
- 승인자: GitHub 관리자 serithemage인 사용자, Codex 대화에서 동일 이름 재생성 승인
- 시행일: 2026-11-27

## 배경

서버에서 생성된 초기·병합 커밋 메타데이터의 이메일을 공개 범위에서 제외할 필요가 생겼습니다. 파일 본문 외에도 커밋 작성자와 committer를 확인합니다.

## 검토 대안

- 단순 이력 수정: 기존 PR 참조에 과거 이력이 남을 수 있습니다.
- 비공개 유지: 승인된 공개 커뮤니티와 홈페이지를 운영할 수 없습니다.
- 동일 이름 재생성: 로컬 백업 후 깨끗한 이력과 운영 자료를 복원합니다.

## 결정과 근거

사용자의 삭제·동일 이름 재생성 승인에 따라 community와 website를 복구합니다. Organization과 operations는 유지합니다. 복구 중에는 비공개와 Actions 비활성 상태로 검사하고, noreply 커밋 검증 후 공개합니다. 초기 커밋은 로컬에서 생성하고 CLI squash 병합에도 noreply 작성자 이메일을 명시합니다. Actions 문서 검사에서 가져온 전체 이력의 작성자·committer 이메일을 검사합니다.

## 재검토 조건

GitHub 인증·병합 방식 변경, 자동 문서 편집 도입, 새 운영자 참여 시 개인정보 경계를 재점검합니다. 삭제된 저장소의 제3자 복사본·캐시까지 제거했음을 보장하지 않습니다. 세부 운영 정책과 외부 초대·과금·AWS 연결·봇 배포는 별도 승인 범위입니다.
