# 사례 제목

- 공개 동의된 발표자 또는 팀 명칭 / 분야·태그:
- 문제 또는 창작 의도 / 기존 방식과 제약:
- 사용 도구·모델 / 버전·조건:
- 제작 과정 / 선택과 시행착오:
- 공개 가능한 결과물 링크:
- 검증 방법 / 피드백 / 근거 있는 측정값:
- 실패·한계 / 미해결 사항:
- 공개 가능한 재현 자료 / 프롬프트:
- 데이터·음원·영상·이미지·코드·초상·목소리 권리:
- 라이선스 / 공개 범위 / 동의 확인:
- 운영진 검수 / 공개 승인 기록:

공개 동의와 권리 검토 전에는 게시하지 않습니다. 대화 원문이나 회원 명단을 옮기지 않습니다.
