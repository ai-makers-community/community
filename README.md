# AMC · AI Makers Community

**Imagine. Make. Share.**

AI를 활용해 개발·업무·음악·영상·디자인 분야의 문제를 해결하고 창작 경험을 나누는 비영리 커뮤니티입니다. 프로그래밍 경험이나 직업과 무관하게 참여할 수 있습니다.

- SHARE: 과정, 결과, 실패와 재사용 가능한 교훈을 공유합니다.
- MAKE: 사례 발표·강의·핸즈온과 작은 협업으로 결과물을 만듭니다.
- CONNECT: 현장 실무자·개발자·크리에이터가 서로의 경험을 연결합니다.

[홈페이지](https://ai-makers-community.github.io/website/) · [공개 의견 수렴](../../discussions) · [제안 양식](../../issues/new/choose)

## 참여와 정보 공개

행사 일정과 신청 경로는 아직 확정되지 않았습니다. 확정 후 홈페이지에 안내합니다. 비공개·실명제 단톡방은 AMC 모임의 실제 참가자에게만 운영진 확인과 규칙 동의 후 개별 초대합니다. 초대 링크와 참가자 명단은 공개하지 않습니다. 회원에게 GitHub 사용을 강제하지 않습니다.
