# 개인정보와 공개 경계

공개 저장소·Issues·Discussions·Projects·PR·Actions 로그·Pages에는 단톡방 초대 링크, 회원 실명 명단, 참가 확인 자료, 개인 연락처, 신고 기록, 대화 원문, 비밀키, 비공개 후원 조건을 넣지 않습니다.

`operations`는 비공개 운영 기획 저장소입니다. 모든 조직 구성원에게 자동 접근을 주지 않습니다. 비공개 저장소라는 이유만으로 개인정보 수집을 시작하지 않습니다. 처리 목적·최소 항목·담당자·보관 기간·삭제 방법·비공개 문의 경로를 먼저 확정해야 합니다.

단톡방은 실제 AMC 모임 참가를 확인한 뒤 본인 이름 표시와 규칙 동의를 거쳐 수동 초대합니다. 주민등록번호나 신분증 사본을 요구하지 않습니다. 탈퇴·퇴장 시 단톡방과 관련 접근권한을 회수하고 고지된 정책에 따라 개인정보를 삭제합니다. 보관 기간과 삭제 요청 채널은 미확정입니다.

사진·영상·발표·작품·사례는 목적별 공개 동의와 권리 확인 후 운영진이 검수합니다. 공개 동의를 받지 않은 원문이나 개인 식별 정보는 공개 초안에도 넣지 않습니다. 공개 철회 요청의 실제 접수 경로는 후속 확정 사항입니다.

노출이 발견되면 추가 공개를 멈추고 관리자에게 비공개로 알립니다. 운영진은 게시물 제거, 토큰 폐기, 저장소 이력·로그·캐시·파생 자료의 노출 범위를 확인하고 필요한 후속 조치를 결정합니다. 자동 검사는 사람의 공개 검토를 대신하지 않습니다.
